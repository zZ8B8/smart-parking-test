## 用例设计说明

| 方法 | 用在哪 |
|---|---|
| **等价类划分** | 车牌格式（5 组非法）、日期格式（4 组非法）、状态筛选、车位类型 |
| **边界值分析** | 免费时长 900/901 秒、恰好 1/2/3 小时、24 小时封顶、车位恰好停满、61 分钟零头 |
| **状态迁移测试** | 车辆 在场 → 出场；以及重复出场这一非法迁移 |
| **容量边界测试** | 7 个车位停满、充电位仅 1 个 |
| **并发测试** | `Barrier` 让 12 辆车同时入场、10 辆车同时抢 7 个车位 |
| **幂等性测试** | 重复调用出场接口 |
| **反向用例（多因素交叉）** | 月卡 × 有效期 → 过期卡必须收费 |
| **对照用例** | 月卡车辆 vs 非月卡车辆，行为必须不同 |

## 未覆盖（后续可扩展）

- 跨天停车（超过 24 小时）的封顶计算方式（按自然日还是按 24 小时滚动）
- 月卡到期当天是否仍可免费（业务规则未定义）
- 免费时长内出场再入场的连续计费
- 道闸、地磁等硬件对接与异常（离线、重复上报）
- 性能压测（入场并发上限、道闸响应时间）
