# 接口文档 · 智能停车管理系统

- 基地址：`http://127.0.0.1:5002`
- 请求/响应均为 `application/json; charset=utf-8`
- 路径参数中的中文（车牌）需 URL 编码，服务端会自动解码

**统一响应格式**

```json
// 成功
{ "code": "OK", "data": { } }
// 失败
{ "code": "错误码", "message": "错误描述" }
```

## 接口清单

| # | 方法 | 路径 | 说明 |
|---|---|---|---|
| 1 | GET | `/health` | 健康检查 |
| 2 | GET | `/api/lot/summary` | 车位总览（总数 / 空闲 / 占用 / 按类型明细） |
| 3 | GET | `/api/spots` | 车位列表（可按状态、类型筛选） |
| 4 | POST | `/api/vehicles/entry` | 车辆入场 |
| 5 | POST | `/api/vehicles/exit` | 车辆出场（结算费用） |
| 6 | GET | `/api/tickets` | 停车记录列表（可按车牌 / 状态筛选） |
| 7 | GET | `/api/tickets/{id}` | 停车记录详情 |
| 8 | POST | `/api/cards` | 办理 / 续办月卡 |
| 9 | GET | `/api/cards/{plate}` | 查询月卡 |

### 1. GET /health

```json
{ "code": "OK", "data": { "status": "UP" } }
```

### 2. GET /api/lot/summary

```json
{
  "code": "OK",
  "data": {
    "total": 7, "free": 7, "occupied": 0,
    "byType": {
      "NORMAL":     { "total": 4, "free": 4, "occupied": 0 },
      "ACCESSIBLE": { "total": 2, "free": 2, "occupied": 0 },
      "CHARGING":   { "total": 1, "free": 1, "occupied": 0 }
    }
  }
}
```

### 3. GET /api/spots

查询参数：`status`（`FREE` / `OCCUPIED`）、`type`（`NORMAL` / `ACCESSIBLE` / `CHARGING`）

```json
{
  "code": "OK",
  "data": {
    "total": 7,
    "items": [
      { "id": "SP00001", "code": "A-001", "type": "NORMAL",
        "status": "FREE", "plate": null }
    ]
  }
}
```

说明：按 `code` 升序返回。

### 4. POST /api/vehicles/entry

请求：

```json
{ "plate": "津A12345", "spotType": "CHARGING" }
```

`spotType` 可省略（不指定则由系统分配任意类型车位）。

```json
{
  "code": "OK",
  "data": {
    "id": "TK00008", "plate": "津A12345",
    "spot_id": "SP00007", "spot_code": "C-001",
    "entered_at": "2026-09-29 10:30:00",
    "exited_at": null, "duration_minutes": null,
    "fee": null, "status": "PARKING"
  }
}
```

业务规则：
1. 车牌格式校验（省份简称 + 字母 + 5~6 位字母数字，新能源牌 8 位）
2. 同一车牌不能重复入场（已在场则拒绝）
3. 自动分配一个空闲车位；可指定车位类型
4. 该类型车位耗尽时拒绝入场

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `INVALID_PLATE` | 400 | 车牌格式不正确 |
| `ALREADY_PARKED` | 400 | 车辆已在场 |
| `LOT_FULL` | 409 | 暂无可用车位 |

### 5. POST /api/vehicles/exit

请求：`{ "plate": "津A12345" }`

```json
{
  "code": "OK",
  "data": {
    "id": "TK00008", "plate": "津A12345",
    "spot_id": "SP00007", "spot_code": "C-001",
    "entered_at": "2026-09-29 10:30:00",
    "exited_at": "2026-09-29 13:30:00",
    "duration_minutes": 180, "fee": 11.0, "status": "CLOSED"
  }
}
```

业务规则：
1. 按入场至今的时长计费（规则见下）
2. 月卡有效期内免费
3. 结算后释放车位

**计费规则**

| 条件 | 费用 |
|---|---|
| ≤ 15 分钟 | 免费 |
| > 15 分钟 | 首小时 5 元（不足 1 小时按 1 小时） |
| 之后 | 每满 1 小时 3 元（不足 1 小时按 1 小时） |
| 单日上限 | 封顶 40 元 |

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `INVALID_PLATE` | 400 | 车牌格式不正确 |
| `TICKET_NOT_FOUND` | 404 | 未找到该车辆的入场记录 |

> ⚠️ 当前实现的两个问题：
> ① 计费时长**向下取整**，超时零头被抹掉（少收费）→ 见 BUG-S1
> ② 取「最后一条记录」结算，**未校验是否已出场**，重复出场会释放他人车位 → 见 BUG-S2

### 6. GET /api/tickets

查询参数：`plate`（车牌，需 URL 编码）、`status`（`PARKING` / `CLOSED`）

```json
{ "code": "OK", "data": { "total": 1, "items": [ { "...": "停车记录对象" } ] } }
```

### 7. GET /api/tickets/{id}

| 错误码 | HTTP |
|---|---|
| `TICKET_NOT_FOUND` | 404 |

### 8. POST /api/cards

请求：`{ "plate": "津A12345", "validUntil": "2027-12-31" }`

```json
{
  "code": "OK",
  "data": { "plate": "津A12345", "valid_until": "2027-12-31",
            "issued_at": "2026-09-29 10:00:00" }
}
```

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `INVALID_PLATE` | 400 | 车牌格式不正确 |
| `INVALID_DATE` | 400 | 有效期不是 `YYYY-MM-DD` 格式 |

> ⚠️ 当前实现**未校验有效期**，过期月卡依然免费 → 见 BUG-S4

### 9. GET /api/cards/{plate}

| 错误码 | HTTP |
|---|---|
| `CARD_NOT_FOUND` | 404 |

## 错误码总表

| 错误码 | HTTP | 含义 |
|---|---|---|
| `OK` | 200 | 成功 |
| `INVALID_JSON` | 400 | 请求体不是合法 JSON |
| `INVALID_PLATE` | 400 | 车牌格式不正确 |
| `INVALID_DATE` | 400 | 日期格式不正确 |
| `ALREADY_PARKED` | 400 | 车辆已在场 |
| `LOT_FULL` | 409 | 暂无可用车位 |
| `TICKET_NOT_FOUND` | 404 | 停车记录不存在 |
| `CARD_NOT_FOUND` | 404 | 月卡不存在 |
| `NOT_FOUND` | 404 | 接口不存在 |
| `INTERNAL_ERROR` | 500 | 服务内部错误 |

## 数据结构

### 车位（Spot）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 车位 ID，如 `SP00001` |
| `code` | string | 车位编号，如 `A-001` / `C-001` |
| `type` | string | `NORMAL` / `ACCESSIBLE` / `CHARGING` |
| `status` | string | `FREE` / `OCCUPIED` |
| `plate` | string \| null | 占用该车位的车牌 |

### 停车记录（Ticket）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 记录 ID，如 `TK00008` |
| `plate` | string | 车牌 |
| `spot_id` / `spot_code` | string | 车位 ID / 编号 |
| `entered_at` / `exited_at` | string \| null | 入出场时间 `YYYY-MM-DD HH:MM:SS` |
| `duration_minutes` | int \| null | 停车时长（分钟），出场后填充 |
| `fee` | float \| null | 费用，出场后填充 |
| `status` | string | `PARKING`（在场） / `CLOSED`（已出场） |

### 月卡（Card）

| 字段 | 类型 | 说明 |
|---|---|---|
| `plate` | string | 绑定车牌 |
| `valid_until` | string | 有效期至 `YYYY-MM-DD` |
| `issued_at` | string | 办理时间 |

### 车位类型 / 状态 / 记录状态

| 枚举 | 取值 |
|---|---|
| 车位类型 | `NORMAL` 普通 · `ACCESSIBLE` 无障碍 · `CHARGING` 充电 |
| 车位状态 | `FREE` 空闲 · `OCCUPIED` 占用 |
| 记录状态 | `PARKING` 在场 · `CLOSED` 已出场 |
