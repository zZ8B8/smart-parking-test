# 智能停车管理系统 · 接口文档

| 项目 | 内容 |
| --- | --- |
| 服务地址 | `http://127.0.0.1:5002` |
| 数据格式 | `application/json`（请求与响应） |
| 字符集 | UTF-8 |
| 鉴权方式 | 本版本无鉴权（靶场简化） |
| 文档版本 | V1.0 |

---

## 1. 通用约定

### 1.1 统一响应格式

**成功**（HTTP 200）：

```json
{ "code": "OK", "data": { } }
```

**失败**（HTTP 4xx / 5xx）：

```json
{ "code": "INVALID_PLATE", "message": "车牌格式不正确：BAD" }
```

> 判断是否成功，**看 HTTP 状态码 + `code` 字段**。

### 1.2 错误码表

| code | HTTP | 含义 | 常见触发 |
| --- | --- | --- | --- |
| `OK` | 200 | 成功 | — |
| `INVALID_PLATE` | 400 | 车牌格式不正确 | 空车牌、格式不符 |
| `INVALID_DATE` | 400 | 有效期格式错误 | 不是 `YYYY-MM-DD` |
| `INVALID_PARAM` | 400 | 参数无效 | 缺少字段（如时钟接口） |
| `ALREADY_PARKED` | 409 | 车辆已在场 | 同车牌重复入场 |
| `LOT_FULL` | 409 | 暂无可用车位 | 车位耗尽、指定类型无空位 |
| `TICKET_NOT_FOUND` | 404 | 停车记录不存在 | 出场时无入场记录 |
| `CARD_NOT_FOUND` | 404 | 该车牌未办理月卡 | 查询不存在的月卡 |
| `NOT_FOUND` | 404 | 接口不存在 | 访问未定义接口 |
| `INTERNAL_ERROR` | 500 | 服务端异常 | 未捕获错误 |

### 1.3 数据库连接（Navicat）

| 项 | 值 |
| --- | --- |
| 主机 | `127.0.0.1` |
| 端口 | `3306` |
| 用户 | `root` |
| 密码 | `123456` |
| 数据库 | `smart_parking` |

## 2. 系统接口

### 2.1 健康检查

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/health` |

```json
{ "code": "OK", "data": { "status": "UP", "db": "10.4.14-MariaDB" } }
```

### 2.2 重置数据（测试便利接口）

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/dev/reset` |

把数据恢复到初始状态（清空业务数据、重置车位与月卡、**时钟归零**）。仅用于测试。

```json
{ "code": "OK", "data": { "reset": true } }
```

### 2.3 测试时钟

| 项 | 值 |
| --- | --- |
| 方法 | `GET` / `POST` |
| 路径 | `/api/dev/clock` |

计费依赖停车时长，测试中不可能真等 3 小时。此接口提供一个全局时间偏移量，
业务层取时间时都会加上它，从而模拟「车已停了 N 小时」。

**POST 请求体（二选一）**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| advance | int | 把时钟**累加**前移这么多秒 |
| reset | bool | 置为 true 时把偏移量归零 |

```json
// 请求：前移 3660 秒（1 小时 1 分）
{ "advance": 3660 }
```

**响应**

```json
{ "code": "OK", "data": { "offsetSeconds": 3660, "virtualNow": "2026-10-08 11:42:39" } }
```

> ⚠️ 只影响本服务的计时逻辑，不修改操作系统时间。

### 2.4 数据一致性自检

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/consistency` |

校验三条不变量：占用车位数 = 在场记录数；占用车位都有对应在场记录；车位流水收支平衡。

**一致时**

```json
{ "code": "OK", "data": { "ok": true, "problems": [] } }
```

**不一致时**

```json
{
  "code": "OK",
  "data": {
    "ok": false,
    "problems": [
      { "rule": "occupied_spots_equals_open_tickets",
        "detail": "占用车位 0 个，但在场记录有 1 条" }
    ]
  }
}
```

## 3. 车位接口

### 3.1 车场总览

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/lot/summary` |

```json
{
  "code": "OK",
  "data": {
    "total": 7, "free": 7, "occupied": 0,
    "byType": {
      "NORMAL":     { "total": 4, "free": 4, "occupied": 0 },
      "ACCESSIBLE": { "total": 2, "free": 2, "occupied": 0 },
      "CHARGING":   { "total": 1, "free": 1, "occupied": 0 }
    }
  }
}
```

### 3.2 车位列表

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/spots` |

**查询参数**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| status | string | `FREE` / `OCCUPIED`，可选 |
| type | string | `NORMAL` / `ACCESSIBLE` / `CHARGING`，可选 |

**响应**

```json
{
  "code": "OK",
  "data": {
    "total": 7,
    "items": [
      { "id": 1, "code": "A-001", "type": "NORMAL",
        "status": "FREE", "plate": null }
    ]
  }
}
```

> 车位按 `code` 升序返回。

## 4. 车辆进出接口

### 4.1 车辆入场

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/vehicles/entry` |

**请求体**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plate | string | 是 | 车牌，省份简称 + 字母 + 5~6 位字母数字 |
| spotType | string | 否 | 指定车位类型，不传则不限 |

```json
{ "plate": "京A12345", "spotType": "CHARGING" }
```

**成功响应**

```json
{
  "code": "OK",
  "data": {
    "id": 1, "plate": "京A12345",
    "spot_id": 1, "spot_code": "A-001", "spot_type": "NORMAL",
    "entered_at": "2026-10-08 10:41:38",
    "exited_at": null, "duration_minutes": null, "fee": null,
    "status": "PARKING"
  }
}
```

**失败示例**

| 场景 | HTTP | code |
| --- | --- | --- |
| 车牌为空 / 格式错 | 400 | `INVALID_PLATE` |
| 同一车牌已在场 | 409 | `ALREADY_PARKED` |
| 无可用车位 | 409 | `LOT_FULL` |

> ⚠️ BUG-S3：并发调用本接口时，「查空闲车位」与「占用车位」之间存在竞态窗口，
> **同一个车位会被分配给多辆车**。

### 4.2 车辆出场

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/vehicles/exit` |

**请求体**

```json
{ "plate": "京A12345" }
```

**成功响应**

```json
{
  "code": "OK",
  "data": {
    "id": 1, "plate": "京A12345",
    "spot_id": 1, "spot_code": "A-001", "spot_type": "NORMAL",
    "entered_at": "2026-10-08 10:41:38",
    "exited_at": "2026-10-08 11:42:40",
    "duration_minutes": 61,
    "fee": 5.0,
    "status": "CLOSED"
  }
}
```

**失败示例**

| 场景 | HTTP | code |
| --- | --- | --- |
| 车牌格式错 | 400 | `INVALID_PLATE` |
| 该车牌没有入场记录 | 404 | `TICKET_NOT_FOUND` |

> ⚠️ BUG-S1：`fee` 的计算用了向下取整，**不足 1 小时的零头被抹掉**（少收钱）。
> ⚠️ BUG-S2：本接口**不幂等** —— 重复调用会重复释放车位；
> 若该车位已被另一辆车占用，会把别人的车位一起释放掉。
> ⚠️ BUG-S4：过期月卡同样返回 `fee = 0.0`（不应免费）。

## 6. 月卡接口

### 6.1 月卡列表

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/cards` |

```json
{
  "code": "OK",
  "data": {
    "total": 2,
    "items": [
      { "plate": "京A12345", "valid_until": "2027-12-31",
        "issued_at": "2026-01-01 09:00:00", "expired": false },
      { "plate": "京B00001", "valid_until": "2024-01-01",
        "issued_at": "2023-01-01 09:00:00", "expired": true }
    ]
  }
}
```

### 6.2 办理 / 续办月卡

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/cards` |

**请求体**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plate | string | 是 | 车牌 |
| validUntil | string | 是 | 有效期，`YYYY-MM-DD` |

```json
{ "plate": "京C11111", "validUntil": "2028-06-30" }
```

**成功响应**

```json
{
  "code": "OK",
  "data": { "plate": "京C11111", "valid_until": "2028-06-30",
            "issued_at": "2026-10-08 10:45:00", "expired": false }
}
```

> 同一车牌重复办理会**更新**原卡，不会新增。

**失败**：`400 INVALID_PLATE`、`400 INVALID_DATE`。

### 6.3 查询单车牌月卡

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/cards/{plate}` |

**失败**：`404 CARD_NOT_FOUND`。

> 注意：车牌含中文，URL 需做百分号编码。例如 `京A12345` →
> `/api/cards/%E4%BA%ACA12345`（Postman/Apifox 会自动处理）。

## 8. 导入 Postman / Apifox 的最小请求集合

先设环境变量 `baseUrl = http://127.0.0.1:5002`：

```bash
# 0. 重置数据
POST {{baseUrl}}/api/dev/reset
Body: {}

# 1. 看车场总览
GET {{baseUrl}}/api/lot/summary

# 2. 车辆入场（记下 spot_code 与 ticket id）
POST {{baseUrl}}/api/vehicles/entry
Body: {"plate":"京A77777"}

# 3. 把时钟前移 1 小时 1 分，模拟停车时长
POST {{baseUrl}}/api/dev/clock
Body: {"advance":3660}

# 4. 出场结算（观察 fee，应为 8.0，实际 5.0 → BUG-S1）
POST {{baseUrl}}/api/vehicles/exit
Body: {"plate":"京A77777"}

# 5. 重复出场一次（观察是否被拒绝 → BUG-S2）
POST {{baseUrl}}/api/vehicles/exit
Body: {"plate":"京A77777"}

# 6. 过期月卡的车停 3 小时再出场（观察是否免费 → BUG-S4）
POST {{baseUrl}}/api/vehicles/entry
Body: {"plate":"京B00001"}
POST {{baseUrl}}/api/dev/clock
Body: {"advance":10800}
POST {{baseUrl}}/api/vehicles/exit
Body: {"plate":"京B00001"}

# 7. 一致性自检（异常操作后应能发现问题）
GET {{baseUrl}}/api/consistency
```
