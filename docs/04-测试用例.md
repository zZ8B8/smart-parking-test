# 智能停车管理系统 · 测试用例

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 智能停车管理系统（smart-parking）V1.0 |
| 文档类型 | 测试用例 |
| 设计方法 | 等价类划分、边界值分析、状态机法、场景法、错误推测 |
| 用例编号规则 | `TC-模块-序号` |
| 优先级 | P0 最高 → P3 最低 |

**通用前置条件**：数据库已 `python init_db.py` 初始化；服务运行在 `http://127.0.0.1:5002`；
每条用例执行前数据与测试时钟均已重置。

**时间模拟说明**：计费用例中的「停车 N 小时」通过测试时钟接口实现：
`POST /api/dev/clock` body `{"advance": 秒数}`。

**结果标记**：✅ 通过　❌ 失败（发现缺陷）
